# Changelog

All notable changes to TN Login with Email are recorded here.

## 1.0.1 - 2026-09-26

- Align WordPress 7.0 / PHP 7.4 metadata, GPL/readme packaging and project-authored CSS units with current Codex standards.
- Remove independent GitHub update checks and delegate updates to Techn Update Controller. Keep Beta readiness and existing feature settings, package identity and domain restrictions.
- Standardise update headers and controller-aware Install/Activate/Check links.

## 1.0.0 - 2026-08-16

- Added email-address usernames for standard WordPress and Multisite registration.
- Preserved plus-addressed usernames through WordPress strict username sanitisation.
- Added safe support for network, single-site, and individual-site activation contexts.
- Added native WordPress updates from public GitHub releases.
